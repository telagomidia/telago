# TelaGo — site demonstrativo

Primeiro projeto de teste do Padrão Técnico de Desenvolvimento de Sites v1.

## Arquitetura
Site comercial estático e responsivo, sem banco de dados ou back-end desnecessário.

## Desenvolvimento
```bash
npm install
npm run dev
npm run build
```

## Publicação
O conteúdo pode ser publicado como site estático. Para GitHub Pages, o repositório precisa permitir Pages e o workflow de deploy deve estar habilitado.

> Importante: o número de WhatsApp em `src/main.js` está como placeholder e deve ser substituído pelo número comercial real antes de produção.
